1.3 How to Create a Direct Web Link for Remote Testers

If the tester is evaluating from a different computer or phone without local setup:

  • Method A (Instant Temporary Tunnel - 2 Minutes): With local server running on port 8000, run in terminal:
    npx localtunnel --port 8000
    Share the generated public URL (e.g. https://celldus-preview.loca.lt) with the tester.
  • Method B (Permanent Cloud Deployment): Connect GitHub repository ruviansari/Celldus_Pharma to Render.com or PythonAnywhere for a permanent 24/7 web link.

2. Public Commercial Website Test Suite

Verify that the commercial catalog, live database rendering, and inquiry submission channels function seamlessly for buyers.

TC-WEB-01Homepage & Dynamic Portfolio Counter
High Priority
Test Route:/home/
Pre-conditions:Server running, active formulations in database.
Action Steps:1. Navigate to /home/. 2. Inspect hero banner carousel, active formulation counter, and latest blog cards.
Expected Result:Live database count renders dynamically; hero slider navigates without visual glitches.
TC-WEB-02Catalog Therapeutic Category Filter Tabs
High Priority
Test Route:/product/
Pre-conditions:Multiple therapeutic categories exist (Antibiotics, Pediatric, etc.).
Action Steps:1. Click on category pills (e.g., "Antibiotics", "Pediatric Drops"). 2. Verify products filter instantly.
Expected Result:Only formulations belonging to selected category are displayed without 404 or page crash.
TC-WEB-03Live Product Keyword Search Bar
Medium
Test Route:/product/
Action Steps:1. Type a salt/brand keyword (e.g. Paracetamol, Cefixime) into search bar.
Expected Result:Matching products filter in real-time. If non-matching string entered, displays "No formulations found".
TC-WEB-04Formulation Technical Details & Breadcrumbs
Medium
Test Route:/product_details/<id>/
Action Steps:1. Click "View Details" on any product card. 2. Verify composition, packaging specs, and breadcrumbs. 3. Click "Home" breadcrumb.
Expected Result:Detailed pack size & indications show; breadcrumb link safely returns to /home/ without 404 error.
TC-WEB-05Customer Trade Inquiry Submission
Critical
Test Route:/contact/
Action Steps:1. Fill full name, email, phone, subject, and medicine requirement message. 2. Click "Submit Inquiry".
Expected Result:Green success alert confirms submission; record is instantly created in database CRM table.
